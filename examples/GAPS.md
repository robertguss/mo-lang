# Corpus gaps

Places where a program needed something `spec/grammar.md` and `spec/design-v0/04-syntax.md` do not define. One line per gap: the first file that needed it, what was missing, the default the corpus uses. Robert decides; the corpus only records. Gaps settled by the Session 5 decisions at the foot of `grammar.md` are gone from this list, and the files follow the decisions.

- `types/generics.mo`: no stdlib trait names exist (pick 15's `Comparable` is only an example). Default: the bound names a trait declared in the same file.
- `recipes/rate-limiter.mo`: chapter 6 uses `Limiter`, `ClientId`, and `tokens` without declaring them, and nothing names a type whose fields the implementer chooses. Default: `type ClientId = String` in the module; `tokens` and `limiter` are body-less signatures in the recipe; `Limiter` and `l.capacity` stay undeclared, as in chapter 6. The checker reads an undeclared type in a recipe signature as opaque (the implementer chooses its fields), so a field read on it is not checked at tier 1.
- `effects/timeout.mo`: grammar gives `Fs.read` the error type `FsError` but never lists its variants, and `try` needs them to match the caller's error enum. Default: `FsError` is `Missing(path: String) | Timeout`, marked corpus-only in `toolchain/PRELUDE.md`.
- `payments/refund.mo`: chapter 4 takes `Charge`, `ChargeId`, `Money` from `Payments.Ledger`, which is not written, and also uses `CardNumber`, `RefundRequest`, `RefundCompleted`, `RefundFailed`, `t0`, `db.find_charge`, `db.save_charge`, `Charge.fixture`, `charge.refunded?`, `Money.cents`, and `Money.zero` without declaring them. Default: corpus-only stand-ins in `toolchain/PRELUDE.md`. `find_charge` and `save_charge` fail with `LedgerError`, whose one variant is `Timeout`, because `try` in `refund` can re-tag only variants `RefundError` also has. Nothing says what a `Ledger.fixture()` holds. Default: it finds every id as an unrefunded charge of 10_000 captured at `Time.fixture()`, and every save succeeds, so the queue test's refunds go through.
- `payments/refund.mo`: the corpus copy differs from chapter 4 in six places. Three are rules the toolchain enforces. Its first test binds `result = ...`, but `result` is a keyword (grammar §1), so the copy names it `outcome`. `within_window?` and `refund` each have a `requires` with no `test rejects` (MO0311), so the copy adds one `test rejects` for each. Its `verified:` line is written by hand (MO0317), so the copy leaves it off. The fourth is a false property: `mo test` found, on the first seed, a charge that is already refunded, which `apply_refund` answers with `AlreadyRefunded`. The copy's guard adds `!charge.refunded? and`. The fifth and sixth come with processes (step 4): `RefundQueue` gains `message Done : UInt32` so a test can read `done` with an `ask`, and the copy adds the test that starts the queue, sends `Enqueue` twice and `Drain`, and asks for `Done`.
- `types/generics.mo`: the grammar has no syntax that declares a type parameter; `fn first(xs: List(T))` just uses `T`. Default in the checker: an undeclared one-letter type name in a function signature is a type parameter of that function; anywhere else it is an unknown type.
- `programs/logstat/parse.mo`: nothing turns bytes, or part of a `String`, back into a `String` (no substring, split, or byte-to-text). Default: a table of the 95 printable ASCII characters as one-character strings, looked up per byte and joined by interpolation. A byte outside 32 to 126 has no text, so a line with a non-ASCII path is malformed even though the file is valid UTF-8.
- `programs/logstat/parse.mo`: no conversion between integer widths (grammar's Literals decision names `n.to_u32`, the prelude has none). Default: a digit's value is a ten-arm `case` giving `UInt64`; every count stays `UInt64`, and "fits `UInt32`" is the refinement `type Millis = UInt64 where value <= 4_294_967_295`.
- `programs/logstat/parse.mo`: nothing parses a `String` into a number or a `Time`, and nothing builds a `Time` from a calendar date. Default: digits folded by hand; a timestamp is `UInt64` seconds from a fixed origin (Hinnant's days_from_civil), and `Time` is not used.
- `programs/logstat/parse.mo`: `List` has no index, slice, or concatenation. Default: `reduce` with a counter in a tuple accumulator (`slice`, `part`, `first_n`), and `append` by pushing each element.
- `programs/logstat/stats.mo`: no sort, and a signature cannot name a function type, so one sort cannot take its comparison. Default: an insertion into a sorted list, written once per element type (`kept_slowest` for records, `inserted` for counts).
- `programs/logstat/stats.mo`: no map or dictionary. Default: the busiest paths are a `List(Count)` searched linearly for each record.
