# Direction 26: Optimize for developer happiness AND agent happiness

Robert's favorite language to read and write is Ruby (Matz's "developer happiness"). Mo's syntax must be enjoyable to read. A Rust/Gleam-shaped brace syntax was rejected on sight. Direction: Ruby's look with Go's discipline. Precedents: Crystal (Ruby syntax + static types + native binaries) and Elixir (Ruby's feel on the BEAM). One way to write each thing, resolved by the formatter: Ruby's look, not Ruby's freedom.
