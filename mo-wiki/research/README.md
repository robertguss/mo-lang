# research/

Pages backed by reading, not by training data: every page names its sources under `raw/`, and the linter checks that the snapshots it cites have not drifted. One page per topic, dated. Rewritten 17 Sep 2026; the first version of this file listed the folders below as planned.

- `comparisons/` — Mo held against one other language or system, one page each (`type: comparison`): Elixir, Go, Rust, Roc, Koka, Austral, Unison, Verse, Hylo, MoonBit, Motoko, Bosque, Aube, SPARK/Ada and Dafny, and the agent-native cluster. Written 12 Sep; each page's "Mo today" lines are that date's reading, and the current state is in the spec chapters and [[state-of-the-project]].
- `concepts/` — one researched topic per page (`type: concept`): the language landscape and its second lane, supply-chain defenses, the capability-module lineage, the case against new languages, the empirical validation plan, agents and verification in 2026, safety-critical coding standards, reliability and testing philosophies, the eight author profiles (`author-*.md`), and from 16 Sep the Hermes lane's dated daily notes (`hermes-daily-*.md`, see [[hermes-research-monitoring]]).
- `languages/` — a language's history and what Mo takes from it (`type: research`), thirteen pages from the plang history run of 13 Sep (`raw/plang-history-2026-09/`).

The maps under `maps/` put these in reading order by subject; [[the-thesis-and-its-evidence]] is the one to start from. The raw material is under `raw/`: `articles/`, `papers/`, `notion/`, `research-runs/` (the Perplexity runs), and `plang-history-2026-09/`.
